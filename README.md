# 🚀 GenAI-Powered Resume Analyzer & ATS Checker

An automated ATS screening platform built using **Python**, **Streamlit**, and **Google Gemini API** to evaluate resumes against Job Descriptions using semantic AI analysis.

🔗 **Live Application:** https://ai-resume-analyzer-shivraj.streamlit.app

---

## ✨ Features
* **Semantic Analysis:** Goes beyond exact keyword matching to understand domain context using Google Gemini.
* **ATS Score Generation:** Calculates real-time match percentage between Resume and Job Description.
* **Gap Analysis:** Highlights missing technical skills, keywords, and structural improvements.
* **Secure Environment:** Built with Streamlit Secrets for safe API key management.

---

## 🛠️ Tech Stack
* **Language:** Python
* **Frontend:** Streamlit
* **AI Model:** Google Gemini API
* **PDF Parser:** PyPDF2
